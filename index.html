How to use

  1. Open any .html file in your web browser (Chrome, Edge, Firefox, Safari). No account, no install, no internet needed.
  2. Click into the shaded fields and type, or print first and write by hand.
  3. Print (Ctrl+P / Cmd+P). Turn on "Print background graphics" so headers show. Pages are US Letter with large-print text and big checkboxes.
  4. Or read a .md file in any Markdown reader or text editor.
